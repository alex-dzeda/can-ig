# CMS-Aligned Network Implementation Guide

## Background

This Implementation Guide (IG) establishes standard protocols and interactions for operating within a CMS-aligned network infrastructure. 

## Purpose

The primary purpose of this guide is to consolidate referenced specifications and provide a clear, standardized pathway to implementation. Initial focus and guidance are centered on **Individual Access Services (IAS)**.
